# 🌻 Yellow Flowers on September 21

A simple and creative webpage celebrating **yellow flowers on September 21**, built with **HTML**, **CSS** and **JavaScript**, including animations and background music.  

🌐 **Live Demo:** [View on GitHub Pages](https://erickdc7.github.io/yellow-flowers-september-21/)

## ✨ Features

- Animated yellow flowers with HTML & CSS.  
- Subtle effects and animations (growing grass, moving elements, petals).  
- Background music with a play trigger (autoplay is limited by browsers).  
- Responsive layout for desktop and mobile.  

## 🛠️ Built With

- HTML5  
- CSS3 (animations, transitions, responsive design)  
- JavaScript (DOM interactions, music trigger)
